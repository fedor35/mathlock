# Режим «Чтение вслух»

Ребёнок читает текст вслух, чтобы разблокировать телефон. Всё работает без интернета.

## Конвейер

```
микрофон 16 кГц → фронтенд (лог-мел / сырой звук) → CTC-модель (NPU или CPU) → жадный декодер
   → ReadingMatcher (буквенное выравнивание с текстом, по словам: OK / ОШИБКА / ещё не прочитано)
   → подсветка слов на экране; все слова OK → разблокировка
```

Модули: `android/reading` (движок, без UI), `android/readbench` (стенд замеров, отдельный пакет — без блокировки),
`ml/` (экспорт, квантование, озвучка, фикстуры). Тексты: `content/<язык>/texts.jsonl`.

## Переключаемость языков и моделей

Два независимых слоя:

* `LanguageSpec` — правила языка: алфавит, гласные, нормализация букв (ё→е), «похожие» пары, которые не считаются
  ошибкой чтения (безударные а/о, оглушение), слогораздел для отображения. Есть `ru`, черновик `kk`.
* `AsrModelSpec` — манифест модели `*.model.json` рядом с `.onnx`: языки, единицы (`letters`/`phonemes`),
  фронтенд, словарь CTC, blank, файлы под CPU / HTP fp16 / HTP int (QDQ), окно статической формы.
  Модель меняется без правки кода; на язык может быть несколько моделей.

`ReadingMatcher` работает с «единицами сравнения»: на одной стороне `ReadingText.letters`, на другой выход модели.
Для фонетичной орфографии (ru, kk) это буквы. Для английского буквенная сверка плохая (spelling ≠ sound),
поэтому там нужна фонемная модель (wav2vec2-phoneme / MMS, espeak-IPA) и словарь/G2P для текста.

| Язык | Модель сейчас | План |
|---|---|---|
| ru | GigaAM-v3 `ctc` (символы, 240M, MIT) | дообучить на записях сына (детская речь) |
| kk | — | дообучить GigaAM-v3 с новой CTC-головой (42 буквы) на KSC2 (ISSAI) + детские записи |
| en | — | фонемная CTC (wav2vec2-xlsr-espeak / MMS) + CMUdict; либо Parakeet-CTC по буквам с G2P-сверкой |

QDQ A16W8 на тестовых клипах распознаёт так же, как fp32 (`reads_fixture.json`).

## Сверка (ReadingMatcher)

Пробелы гипотезы игнорируются: при чтении по слогам ASR выдаёт «ма ма мы ла». Цены: вставка 0,35 (повторы слогов),
пропуск 1, пропуск последней буквы слова 1,6 (окончания), замена 1, «похожая» замена 0,4. Слово засчитано при
доле ошибок ≤ 0,25; однобуквенные и двубуквенные предлоги прощаются, если слова вокруг прочитаны.
Непрочитанный хвост бесплатен, поэтому подсветка идёт по ходу чтения.
На 36 клипах синтезированного детского чтения все решения верные (`FixtureTest`). Пороги будут подстраиваться на живых записях.

## Ударения и интонация (план)

По выравниванию CTC находим отрезки гласных и считаем у каждой длительность, громкость и F0.
Ударную гласную определяет классификатор, обученный сначала на озвучке (ударение известно из текста), потом на записях ребёнка.
Интонацию проверяем по контуру F0 на последнем слове предложения (. ? !) в сравнении с эталонной озвучкой.
Результат идёт только в подсказку («послушай, как правильно») и не мешает разблокировке.

## Озвучка

OmniVoice на r99950x в максимальном качестве (fp32, 64 шага). На каждую фразу генерируется n кандидатов,
лучший выбирается по CER GigaAM. Персонажи заданы через voice design, удачные образцы фиксируются для клонирования.
